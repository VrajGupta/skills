# Handoff: gauntlet-loop skill

## Scope
Added a standalone `gauntlet-loop` skill for one-shot prompts, UI work, writing,
research, and small implementation tasks. It supports prompt mode, run mode, and UI
mode without changing the planner → coder → debugger → reviewer pipeline.

## Behavior contract
- Requires a named, fetchable, comparable quality bar.
- Prompt mode returns a paste-ready maker/critic prompt.
- Run mode requires a mechanical done-condition and a fresh critic where available.
- UI mode compares matching screenshots and checks responsive behavior, accessibility,
  typography, interaction states, reduced motion, and loading/empty/error states.
- Critic must return a binary pass or one falsifiable biggest gap.
- Default budget is five attempts; exhaustion is a blocker, not success.
- Existing safety, accessibility, validation, security, and data-loss protections stay
  mandatory.
